About

Porchlight sees cars, wearables and household gadgets that broadcast a persistent ID. It can't see phones: iOS and Android rotate their Bluetooth addresses and broadcast no persistent ID, so a person carrying only a phone is invisible. AirTag-style trackers rotate too, and Porchlight doesn't look for unwanted trackers.

Identifiers are never shown: only vendor, product, ID type and a 4-character hint.
